# Todo List (Group 6)

A simple web app project that helps users organize and manage daily tasks.

## About

The Todo List system is designed to make it easier to keep track of daily activities. Users can create an account, sign in, and manage tasks from a dashboard.

## Main Features

- Create an account and sign in
- View tasks on a dashboard
- Add a new task
- Edit an existing task
- Mark a task as complete
- Delete a task
- Sign out

## Tech Stack

| Technology | Purpose |
| --- | --- |
| HTML | Page structure and content |
| CSS | Styling and layout |
| JavaScript | Client-side interaction and validation |
| PHP | Server-side logic, authentication, and form processing |
| MySQL | Database storage and data management |
| Git & GitHub | Version control and team collaboration |

frontend/

## Current Status

The repository currently includes the frontend landing page, sign-in page, and sign-up page with a minimal design. Backend and database functionality (PHP/MySQL) can be added as the project progresses.
